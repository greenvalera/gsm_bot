<objective>
Close the schema half of G-02-5: WR-08 (PlanningParticipant.membershipId has no
foreign key and telegramUserId has no index) and WR-06 (a dead PlanningRoundStatus
member and dead action members in the Zod callback boundary). Also add the
callback_actions expiry index that the 02-11 retention sweep needs, because this is
the only plan in the gap-closure set that owns prisma/schema.prisma.

Purpose: 02-VERIFICATION.md records the participant snapshot as relying on an
undeclared precondition — its referential integrity holds today only because roster
removal happens to be a soft delete, and nothing in the schema says so. Phase 3 reads
these rows as a durable cross-phase contract (D-09/D-11) to decide who may answer the
availability card, so a dangling membership id is a cross-phase correctness hazard,
not cleanup. The dead vocabulary is the mirror problem: a validator that accepts
actions the system cannot mint is attack surface for no benefit, and a status the
state machine can never reach invites a later reader to assume an abandonment path
exists.

Output: one reviewed forward migration, a regenerated client, a narrowed callback
vocabulary with its now-unreachable dispatch branch removed, and integration coverage
that proves the constraint and both indexes exist and behave.

Not in scope: the callback_actions retention sweep itself and the confirm-time lineup
lock — both land in 02-11, which depends on this plan for the index and the
constraint.
</objective>
