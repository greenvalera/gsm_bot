## Recorded decisions

**D-30 — the budget is measured in UTF-16 units and the cut is made on code-point boundaries.**
The two are not the same rule and both are required. Telegram counts the limit in UTF-16 code units, so the budget must be `String#length`; a cut mid-surrogate produces a lone surrogate Telegram rejects outright, so the walk must be over code points. The fix accumulates code points while counting units and reserves one unit for the ellipsis. Reversibility: **reversible**.

**D-31 — the ownership acknowledgement is guarded, not made unfailable.**
WR-04's secondary consequence is that `refuseNonAuthor`'s `answerCallbackQuery` is unwrapped, so any rejection escapes to the global bot error handler and the bystander's tap spins. The bound above makes the known cause unreachable; the guard makes the class unreachable. Absorb a rejection at the surface's own catch site — a refusal that cannot be delivered is a logged failure, not an unhandled one. Reversibility: **reversible**.

**D-32 — the enum expectation is a flat, ordered lookup over applied migrations.**
A nested condition over two independent-looking flags encodes a state that migration ordering makes unreachable and would silently produce a wrong expectation if a future migration were inserted out of order. An ordered list of migration-to-labels pairs, taking the last applied, says the same thing for every reachable state, has no dead branch, and fails loudly rather than wrongly. Reversibility: **reversible**.
