## Trust Boundaries

| Boundary | Description |
|---|---|
| settings input/callback → SettingsEditDraft | Untrusted replacement values and tokens must remain actor/chat/field/expiry-bound. |
| committed configuration → Telegram dashboard | Partial reads or draft values must not be represented as authoritative settings. |
| current membership result → settings continuation | Every continuation must fail closed on delay, missing context, or non-admin role. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-14 | Tampering | settings write | high | mitigate | Target-field binding, full reconstructed validation, expected revision, and one transaction prevent invalid/stale writes. |
| T-01-40 | Tampering | timezone edit candidate | high | mitigate | Bind each validated IANA candidate to its own actor/chat/edit/expiry action and write only the selected replacement before Current/New save. |
| T-01-16 | Information disclosure | dashboard/read error | medium | mitigate | Render only a complete committed projection and map failures to generic copy without draft/ID leakage. |
| T-01-33 | Elevation of privilege | mid-flow settings actor | high | mitigate | Acknowledge then refresh role before every input/callback read or mutation; denial deletes actor draft. |
| T-01-17 | Repudiation | duplicate save/keep | low | accept | Single-use actions and revision checks make repeats deterministic with `Already applied.`. |
