- `AuthorizationService.requireCurrentAdministrator(chatId, actorId)` returns only after a fresh Telegram role lookup; on denial it deletes that actor's setup/settings drafts and throws `PermissionDeniedError`.
- `SetupService` methods accept `chatId`, `actorId`, validated input, and `now`; they never accept administrator authority as a caller-supplied boolean.
- `TimezoneResolver.resolve(latitude, longitude): Promise<string>` is fallible; `SetupService.confirmTimezoneCandidate` validates the returned string through `Intl.DateTimeFormat` before storing it in the draft.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Telegram command/location/text/callback → setup adapter | Actor, chat, input, and callback token are untrusted. |
| setup adapter → current membership gateway | Current Telegram role is refreshed before each protected state access. |
| coordinates → timezone resolver | Approximate location is transformed by third-party data and remains a candidate until human confirmation. |
| setup service → PostgreSQL transaction | Only complete validated drafts may become active configuration. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-08 | Elevation of privilege | resumable setup/settings draft | high | mitigate | `AuthorizationService` refreshes role at every boundary and deletes the actor draft on denial per D-14. |
| T-01-09 | Spoofing | draft owner/location sender | high | mitigate | Bind draft and CallbackAction to chat and actor; reject a different sender before resolver or state access. |
| T-01-10 | Tampering | schedule/reminder input | medium | mitigate | Strict parsers plus complete cross-field validation run at field completion and final transaction. |
| T-01-11 | Tampering | timezone inference | medium | mitigate | Validate IANA output, display it as a candidate, and require explicit D-09 confirmation before any draft/active timezone transition. |
| T-01-12 | Repudiation | duplicate/stale save | low | accept | Callback action consumption and revision checks make the result deterministic; structured IDs/action kinds are logged without draft values. |
| T-01-SC | Tampering | approved `tz-lookup` package | high | mitigate | Package was independently human-approved in Plan 01-01 and remains isolated behind `TimezoneResolver` for replacement. |
</threat_model>
