<interfaces>
- `AuthorizationService.requireCurrentAdministrator(chatId, actorId)` returns only after a fresh Telegram role lookup; on denial it deletes that actor's setup/settings drafts and throws `PermissionDeniedError`.
- `SetupService` methods accept `chatId`, `actorId`, validated input, and `now`; they never accept administrator authority as a caller-supplied boolean.
- `TimezoneResolver.resolve(latitude, longitude): Promise<TimezoneResolution>` is package-neutral, where `TimezoneResolution` is `{ kind: "resolved"; candidate: string } | { kind: "ambiguous"; candidates: readonly [string, string, ...string[]] } | { kind: "failure"; cause: "invalid-coordinates" | "empty-result" | "resolver-error" }`.
- `GeoTzTimezoneResolver` imports `find` from `geo-tz/dist/find-now`, validates/de-duplicates all returned IANA strings, maps one result to `resolved`, two or more to `ambiguous`, and converts invalid input, empty/invalid output, and thrown lookup errors to `failure` without leaking internals.
- Callback text contains only a short versioned opaque token; `CallbackAction` supplies chat, actor, kind, target, expiry, and consumption state.
- One CallbackAction is created per valid candidate and binds that IANA string server-side to the active draft. Consuming it copies only the selected string to `SetupDraft.candidateTimezone`; final setup review/save later promotes it to `ChatConfiguration.timezone`.
</interfaces>

## Trust Boundaries

| Boundary | Description |
|---|---|
| Telegram command/location/text/callback → setup adapter | Actor, chat, input, coordinates, and callback token are untrusted. |
| setup adapter → current membership gateway | Current Telegram role is refreshed before each protected state access. |
| coordinates → timezone resolver | Third-party boundary data can produce one, many, no, invalid, or failed results; every valid choice still requires human confirmation. |

| T-01-08 | Elevation of privilege | resumable setup draft | high | mitigate | `AuthorizationService` refreshes role at every boundary and deletes the actor draft on denial per D-14. |
| T-01-09 | Spoofing | draft owner/location sender | high | mitigate | Bind draft and CallbackAction to chat and actor; reject a different sender before resolver or state access. |
